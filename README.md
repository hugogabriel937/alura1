# Monalisa Interativa 🎨

Projeto desenvolvido para o curso Alura - Uma versão interativa e divertida da famosa pintura de Leonardo da Vinci.

## ✨ Características

- **Cores Originais**: Utilizadas as cores autênticas da obra de Leonardo da Vinci
- **Olhos Interativos**: Os olhos acompanham o movimento do seu mouse em tempo real
- **Design Responsivo**: Funciona perfeitamente em dispositivos móveis e desktops
- **Animações Suaves**: Transições fluidas para uma experiência agradável
- **Suporte Touch**: Compatível com dispositivos touchscreen

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura com SVG para desenho vetorial
- **CSS3**: Estilização com gradientes e efeitos visuais
- **JavaScript**: Interatividade e movimento dos olhos

## 📁 Estrutura do Projeto

```
alura1/
├── index.html      # Arquivo HTML principal com o SVG da Monalisa
├── style.css       # Estilos CSS
├── script.js       # Lógica JavaScript para interatividade
└── README.md       # Este arquivo
```

## 🚀 Como Usar

1. Clone ou baixe este repositório
2. Abra o arquivo `index.html` em seu navegador
3. Mova o mouse sobre a imagem da Monalisa e veja os olhos acompanharem!
